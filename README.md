# الشفرة 🕵️ — لعبة كلمات جماعية أونلاين بالعربي

فريقين (أحمر وأزرق)، لكل فريق **رئيس جواسيس** يعطي تلميح بكلمة ورقم، و**عملاء** يخمّنون الكلمات من شبكة 5×5.
الدخول برابط أو باركود (QR)، يشتغل على الجوال والكمبيوتر، والواجهة عربية بالكامل.

🎮 **العب الحين:** https://shifra.srv2082532.hstgr.cloud

## المميزات
- قواعد كاملة: 9/8/7 + القاتل، التلميح + الرقم، التخمين لين الرقم+1، إنهاء التخمين، الفوز والخسارة.
- السيرفر هو الحَكَم: ألوان البطاقات ما توصل إلا لرؤساء الجواسيس (ما أحد يقدر يغش من المتصفح).
- منع التلميح اللي يطابق كلمة في اللوحة (مع توحيد الهمزات والتاء المربوطة والتشكيل و"ال").
- اقتراح البطاقة قبل كشفها (يظهر اسم المقترح عليها).
- سجل اللعب، مؤقت اختياري للدور، خلط الفرق، طرد لاعب ونقل المضيف.
- قائمة أكثر من 500 كلمة عربية + إمكانية إضافة كلماتك الخاصة.
- رابط + باركود + زر مشاركة واتساب، وإعادة اتصال تلقائية لو انقطع النت أو قفلت الجوال.

## النشر على Hostinger VPS (أمر واحد)
1. من **hPanel ← VPS**: تأكد إن النظام **Ubuntu 22.04 أو 24.04**.
2. افتح **Browser terminal** (زر في صفحة الـ VPS) أو ادخل بـ `ssh root@IP`.
3. الصق هذا الأمر:
   ```bash
   curl -fsSL https://raw.githubusercontent.com/SA-502/Code-names/main/deploy/setup-vps.sh -o setup.sh && bash setup.sh
   ```
   - بدون دومين: اللعبة تفتح على `http://IP-السيرفر`.
   - مع دومين: أضف سجل `A` للدومين (`@` و `www`) يأشر على IP السيرفر، وبعدين شغّل `bash setup.sh yourdomain.com` (يطلع HTTPS تلقائياً).
4. اللعبة شغالة 24 ساعة، و PM2 يرجعها تلقائياً بعد أي إعادة تشغيل.

### النشر الحالي (Docker + Traefik على نفس VPS n8n)
اللعبة منشورة كمشروع Docker اسمه `shifra` من ملف `deploy/hostinger-docker-compose.yml` بالمتغيرات:
`SH_REPO=https://github.com/SA-502/Code-names.git` و `SH_BRANCH=main` و `SH_HOST=shifra.srv2082532.hstgr.cloud`.
الحاوية تسحب آخر نسخة من `main` كل ما تنعاد تشغيلها، يعني للتحديث: ارفع على `main` ثم **Restart** للمشروع من Docker Manager في hPanel.

### بديل: Docker
فيه `Dockerfile` و `docker-compose.yml` جاهزين: `docker compose up -d --build` داخل مجلد الريبو (اللعبة على المنفذ 80).

### التحديث لاحقاً
```bash
bash setup.sh            # نفس الأمر يحدّث الكود ويعيد التشغيل (أو: bash setup.sh yourdomain.com)
```

### أوامر مفيدة
- `pm2 logs shifra` سجل الأخطاء
- `pm2 status` حالة اللعبة
- `curl localhost:3000/health` فحص سريع

## الملفات
| الملف | الوظيفة |
|---|---|
| `server/game.js` | قواعد اللعبة (بدون اتصال) |
| `server/rooms.js` | الغرف واللاعبين والأدوار |

## تغيير الاسم أو الكلمات
- الاسم موجود في `public/index.html` و `public/room.html` (كلمة "الشفرة").
- الكلمات في `data/words-ar.json` (مصفوفة JSON). اللعبة تتجنب تلقائياً وضع كلمتين متشابهتين في نفس اللوحة.

> طريقة اللعب مستوحاة من ألعاب الكلمات والجواسيس الجماعية. الاسم والكلمات والتصميم هنا أصلية.
